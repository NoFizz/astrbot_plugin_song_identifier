## 功能简介

- 🎵 **听歌识曲**：引用一条语音、视频或音频文件消息，即可识别出其中播放的歌曲
- 🧠 **自然语言触发**：不用记指令，直接问"这是什么歌？"“BGM 是什么？”，由大模型自主调用识曲工具
- 🔍 **多引擎识别**：内置 5 款识别引擎（ACRCloud、Shazam、讯飞原声/哼唱、讯飞自研 qbh），可按首选→次选→备选自动回退
- 🎤 **哼唱识别**：讯飞系引擎支持旋律哼唱识别，原声与哼唱可独立排列进回退链
- 📋 **多种输出形式**：纯文本（模板可自定义）、竖版图片卡片（上封面 + 下歌名/歌手，高清渲染）、QQ 音乐卡片，任你选择
- 🎼 **歌曲信息增强**：识别后自动补全专辑封面、试听链接与网易云歌曲 ID
- 📦 **音乐卡片平台回退**：卡片发送支持网易云音乐、QQ 音乐双平台自动降级
- 🛠 **可观测**：全流程分步日志（媒体转换、引擎尝试、识别结果、输出形式），开启 Debug 日志后每个环节都有详细记录

## 安装方法

> ⚠️ 本插件**仅支持 OneBot v11（aiocqhttp）平台**，请确保你的协议端（如 LLBot、NapCat 等）以 OneBot v11 反向 WS 方式接入 AstrBot。

### 方法一：通过插件源安装（推荐）

1. 打开 AstrBot WebUI → 插件管理 → 插件市场。
2. 添加插件源（如尚未添加）：
   - 源名称：`AstrBot Official Plugin Market`
   - 源地址：`https://cloud-test.astrbot.app/api/v1/market/plugins.json`
3. 在插件市场中搜索 **听歌识曲**（`astrbot_plugin_song_identifier`），点击安装。
4. 等待安装完成，确认插件已启用。

### 方法二：GitHub 安装

```bash
cd <AstrBot 根目录>/data/plugins
git clone https://github.com/NoFizz/astrbot_plugin_song_identifier.git
```

然后在 AstrBot WebUI → 插件管理 → 重载插件。

### 方法三：手动安装

将插件目录直接放入 AstrBot 的 `data/plugins/` 目录下，然后在 AstrBot WebUI → 插件管理 → 重载插件。

安装后请在插件配置面板中填写至少一个识别引擎的凭据（详见下文「识别引擎」）。

## 插件配置详解

> 以下默认值均为插件**初次安装**时的出厂设置；所有密钥类配置项默认留空，填写后仅保存在 AstrBot 本地配置文件中。

### 触发设置

| 配置项 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| 识曲触发关键词 | string | `识曲` | 引用语音/视频消息后 @bot 并发送该词，直接触发歌曲识别（不经大模型，响应最快） |

> 除了关键词直连，也可以**不触发关键词**：引用消息后用自然语言提问（如"这是什么歌？"），大模型理解意图后会自动调用识曲工具。两条路径互不干扰。

### 识别引擎

**引擎顺序**（三档单选下拉，每档只能选一款，选「留空」则跳过该档）：

| 配置项 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| 首选 | string | `Shazam` | 第一个尝试的引擎 |
| 次选 | string | `留空` | 首选失败或无结果时尝试 |
| 备选 | string | `留空` | 前两档都失败时的兜底 |

可选引擎：

| 引擎 | 说明 |
| --- | --- |
| ACRCloud | 原声识别。需在 console.acrcloud.cn 注册获取凭据；官方哼唱功能未公开，故仅支持原声 |
| Shazam | 零配置即用（非官方逆向接口，稳定性一般），识别失败时作为兜底 |
| 讯飞开放平台/ACRCloud | 原声识别（听歌识曲）。需讯飞开放平台凭据 |
| 讯飞开放平台/ACRCloud·哼唱 | 旋律哼唱识别（哼唱猜歌）。与原声识别使用同一组讯飞凭据，但走独立哼唱路由 |
| 讯飞开放平台/自研 | 旧版 qbh 哼唱接口（哼唱猜歌）。使用同一组讯飞凭据 |

> 各引擎为**独立档位**：原声与哼唱由你自行排列（如 首选=讯飞原声、次选=讯飞哼唱）。ACRCloud 系哼唱功能官方未公开，因此 ACRCloud 仅作原声识别。

**各引擎凭据**：

| 配置项 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| ACRCloud → Host | string | `（空）` | 如 `identify-cn-north-1.acrcloud.cn` |
| ACRCloud → Access Key | string | `（空）` | console.acrcloud.cn 控制台获取 |
| ACRCloud → Access Secret | string | `（空）` | 同上 |
| 讯飞开放平台 → AppID | string | `（空）` | 讯飞开放平台 → 应用 → 歌曲识别 ACRCloud 页面获取 |
| 讯飞开放平台 → APIKey | string | `（空）` | 同上 |
| 讯飞开放平台 → APISecret | string | `（空）` | 同上 |

> 原声识别、ACRCloud·哼唱、自研（qbh）三类讯飞引擎**共用同一组讯飞凭据**，只需填写一次。未配置凭据的引擎在识别时会被自动跳过，不影响其他引擎工作。

### 输出设置

| 配置项 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| 输出形式 | string | `图片` | `文本` / `图片`（竖版卡片：上封面 + 下歌名/歌手，高清渲染）/ `卡片`（QQ 音乐卡片，发送失败自动降级为文本） |
| 文本输出模板 | string（多行编辑器） | `歌名：{title}\n歌手：{artist}` | 文本模式的输出格式，支持占位符与换行（见下方说明） |
| 输出歌名 | bool | `true` | 关闭时歌名占位符被忽略 |
| 输出歌手 | bool | `true` | 关闭时歌手占位符被忽略 |
| 输出试听链接 | bool | `false` | 所有输出形式生效：主内容发送后**分条**发送链接 |
| 音乐卡片平台 → 首选 | string | `网易云音乐` | 卡片模式优先使用的平台 |
| 音乐卡片平台 → 次选 | string | `QQ音乐` | 首选失败时尝试；选「留空」则跳过 |

**文本输出模板说明**：

- 占位符：`{title}` 歌名、`{artist}` 歌手、`{album}` 专辑
- 换行：直接回车，或在模板中写 `\n` / `\r\n` 转义序列
- `{album}` 专辑占位符**仅 ACRCloud 系引擎**（ACRCloud、讯飞开放平台/ACRCloud）有值，其他引擎（Shazam、讯飞开放平台/自研）时自动忽略该占位符，且不留残留分隔符

示例：

```
歌名：{title}
歌手：{artist}
```

### 高级设置

| 配置项 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| 识别超时（秒） | int | `60` | 识别引擎级联（所有引擎）的总超时上限，不包含增强搜索（网易云/QQ，最多约 30 秒） |
| 音频截取时长（秒） | int | `12` | 语音/视频/文件统一截取前 N 秒并重采样为 16k 单声道 wav（约 384KB）；ACRCloud 官方只处理前 12 秒，默认 12 秒已满足识别需求 |
| Debug 日志输出 | bool | `false` | 开启后输出详细分步日志（媒体处理、引擎请求、响应内容等），便于排查问题；关闭后仅输出开始识曲、识别成功/失败等基础日志 |

### 回退链汇总

**识别引擎回退链**：

```
首选 →（失败/无结果/未配置凭据）→ 次选 →（同上）→ 备选 →（全部失败）→ "未能识别出歌曲"
```

> 原声与哼唱是**独立档位**：如需要"原声识别失败后自动哼唱"，把 首选=讯飞开放平台/ACRCloud、次选=讯飞开放平台/ACRCloud·哼唱 即可，回退由级联顺序决定。

**音乐卡片回退链**：

```
首选（默认网易云音乐）→（发送失败/无法构建）→ 次选（默认 QQ音乐）→（失败）→ 降级文本 + 分条试听链接
```

## 使用示例

**① 关键词直连（最快捷）**

1. 群内发送一段语音（播放歌曲 15 秒以上）或视频
2. 引用该消息 + @bot + 发送「识曲」
3. bot 回复：歌名、歌手（+ 分条试听链接，或图片卡片 / QQ 音乐卡片）

**② 自然语言触发（大模型自主调用）**

引用一条语音/视频消息，直接提问：

> "这是什么歌？" / "这段 BGM 是什么？" / "求这首歌的歌名"

大模型会理解意图并自动调用识曲工具完成识别。

**③ 私聊**

直接引用消息 + 「识曲」（私聊无需 @bot）。

## 常见问题

**Q：识别失败"未能识别出歌曲"？**

- 确认音频清晰、音乐声占比高、时长建议 10 秒以上
- 查看日志：开启「高级设置 → Debug 日志输出」后重新识曲，观察各引擎的尝试过程与失败原因
- 检查首选/次选/备选是否配置了对应凭据（未配置的引擎会被跳过）

**Q：图片模式发不出来？**

- 图片生成失败会自动降级为文本 + 链接，属正常设计（可查看日志定位原因）
- 确认「高级设置 → Debug 日志输出」已开启，观察日志中"图片: 下载封面 / 封面加载 / 生成完成"各环节
- 图片卡片为竖版（480×576 设计尺寸，2 倍超采样高清渲染），封面缺失时显示 ♪ 占位块

**Q：卡片模式发不出去？**

- 卡片发送失败会自动降级为文本 + 链接，属正常设计
- 可尝试切换「音乐卡片平台」首选/次选（网易云音乐 163 卡片 / QQ 音乐原生卡片）

**Q：Shazam 引擎需要配置吗？**

不需要，零配置即用。它是免费的非官方接口，稳定性一般，定位为兜底引擎。

**Q：`pip check` 报 aiofiles 版本冲突？**

`shazamio 0.8.1` 声明 `aiofiles<24`，但 AstrBot 核心需要 `aiofiles 25.x`。该冲突是 shazamio 的过窄版本约束，实际代码只用到 `aiofiles.open()`（25.x 完全兼容），Shazam 引擎运行正常，**请勿降级 aiofiles**（会破坏 AstrBot/quart）。

**Q：试听链接打不开？**

链接来自网易云歌曲页（`music.163.com/song/{id}`），部分歌曲可能受版权限制无法在线播放，可在网易云客户端内搜索试听。
